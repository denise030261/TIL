## 코테

### LeetCode 1584. Min Cost to Connect All Points

#### 문제 요약

모든 점을 최소 비용으로 다 연결하기

링크 : https://leetcode.com/problems/min-cost-to-connect-all-points/description/



#### 첫 번째 시도

이 문제는 MST로 처음에는 크루스칼 알고리즘과 UnionFind 알고리즘을 사용하여 문제를 풀었다. 다만 모든 간선을 만드느라 시간이 걸렸다.

```
class Solution {
public:
    vector<int> root;

    int Find(int x)
    {
        if(x==root[x]) return x;
        return root[x]=Find(root[x]);
    }

    void Union(int x,int y)
    {
        x=Find(x);
        y=Find(y);

        if(x>y)
        {
            root[x]=root[y];
        }
        else
        {
            root[y]=root[x];
        }
    }

    int calculate(vector<int>& a,vector<int>& b)
    {
        return abs(a[0]-b[0])+abs(a[1]-b[1]);
    }

    int minCostConnectPoints(vector<vector<int>>& points) {
            if(points.size()==1) return 0;

            int answer=0;
            int n=points.size();
            vector<pair<int,pair<int,int>>> v;
            priority_queue<pair<int,vector<int>>> pq;

            for(int i=0;i<n;i++)
            {
                root.push_back(i);
                for(int j=i+1;j<n;j++)
                {
                    int cost=calculate(points[i],points[j]);
                    v.push_back({cost,{i,j}});
                }
            }

            sort(v.begin(),v.end());

            int edge=0;
            for(int i=0;i<v.size();i++)
            {
                if(edge==n-1) break;
                
                int cost=v[i].first;
                int a=v[i].second.first;
                int b=v[i].second.second;

                if(Find(a)==Find(b)) continue;

                edge++;
                answer+=cost;
                Union(a,b);
            }

            return answer;
    }
};
```



#### 최종

다음은 프림 알고리즘을 사용하여 구하였다. 크루스칼의 방법으로는 N^2의 간선이 생기고 그것들을 정렬을 해야하기 때문에 N^2logN의 시간이 걸리지만 프림 알고리즘을 사용하게 된다면 N^2의 시간이 걸리기 때문이다. 프림 알고리즘은 보통 우선순위 큐를 사용하지만 이 문제에서는 모든 간선들이 다 연결되어 있는 완전 그래프이기 때문에 우선순위 큐가 아닌 배열에 사용하면 최적화가 된다.

```
class Solution {
public:
    int calculate(vector<int>& a,vector<int>& b)
    {
        return abs(a[0]-b[0])+abs(a[1]-b[1]);
    }

    int minCostConnectPoints(vector<vector<int>>& points) {
        int n=points.size();
        int answer=0;

        vector<bool> visited(n,false);
        vector<int> dist(n,INT_MAX);

        dist[0]=0;

        for(int i=0;i<n;i++)
        {
            int u=-1;
            for(int j=0;j<n;j++)
            {
                if(!visited[j] && (u==-1 || dist[u]>dist[j]))
                {
                    u=j;
                }
            }

            visited[u]=true;
            answer+=dist[u];

            for(int j=0;j<n;j++)
            {
                if(visited[j]) continue;

                int cost=calculate(points[u],points[j]);

                dist[j]=min(dist[j],cost);
            }
        }

        return answer;
    }
};
```



#### 나의 생각

처음 이 문제를 풀 때 MST임을 알았지만 알고리즘 로직 자체는 기억이 나지 않았다. 하지만, 풀었고 알고보니 크루스칼로 사용하였다. 다만, 아쉽게도 시간이 걸려 다른 방법은 없을까 찾아보았는데 프림을 사용하는 방법도 있었다. 이 문제를 풀면서 MST의 상황이라도 어떤 상황이냐에 따라서 알고리즘을 선택해야겠다고 생각하였다.
