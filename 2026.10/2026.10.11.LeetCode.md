## 코테

### LeetCode 290. Word Pattern

#### 문제 요약

이 문제는 패턴이 주어졌을 때 그 때의 s의 각 키워드가 1:1 대응인지 파악하는 문제이다.

링크 : https://leetcode.com/problems/word-pattern/description/



#### 문제 풀이

이 문제는 1:1 대응이기 때문에 map(unordered_map이어도 상관없다)을 한 가지가 아닌 두 가지로 만들어 이  두 가지의 쌍방향이 맞는지 확인하는 로직으로 문제를 풀었다.

```
class Solution {
public:
    bool wordPattern(string pattern, string s) {
        vector<char> v;
        for(char c : pattern)
        {
            v.push_back(c);
        }

        vector<string> words;
        string str="";
        for(char s_c : s)
        {
            if(s_c!=' ')
            {
                str+=s_c;
            }
            else
            {
                words.push_back(str);
                str="";
            }
        }
        if(str!="") words.push_back(str);

        if(words.size()!=v.size()) return false;

        map<char,string> m;
        map<string,char> str_m;
        for(int i=0;i<words.size();i++)
        {
            string word=words[i];
            char alpha=v[i];

            if(m.find(alpha)==m.end() && str_m.find(word)==str_m.end())
            {
                str_m[word]=alpha;
                m[alpha]=word;
            }
            else if(word!=m[alpha] || str_m[word]!=alpha)
            {
                return false;
            }
        }

        return true;
    }
};
```



#### 나의 생각

처음에는 한 가지 방향으로 생각하였지만 문제를 다시 읽어보니 1:1인것을 확인하여 두 가지 방향으로 구하였다. 쉬운 문제이긴 하지만 그만큼 문제를 제대로 파악해야겠다고 생각이 들었다.
