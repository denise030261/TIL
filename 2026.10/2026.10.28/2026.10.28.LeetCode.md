## 코테

### LeetCode 134. Gas Station

#### 문제 요약

gas는 얻고 cost는 잃어버릴 때 한 바퀴를 돌 수 있는가

링크 : https://leetcode.com/problems/gas-station/description/



#### 첫번째 시도

처음에 문제를 풀 때 gas와 cost의 차이를 이용하여 첫 양수일 때부터 시작하면 되고 총합이 음수만 아니면 되는 알았다. 하지만 중간에 큰 음수가 있으면 제대로 된 답을 구할 수 없다.

ex)  gas : [5,8,2,8], cost : [6,5,6,6]

```
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        vector<int> v;
        int n=gas.size();

        for(int i=0;i<n;i++)
        {
            v.push_back(gas[i]-cost[i]);
        }

        int sum=0;
        int index=-1;
        int num=INT_MIN;
        for(int i=0;i<n;i++)
        {
            sum+=v[i];
            if(num<v[i])
            {
                num=v[i];
                index=i;
            }
        }

        if(sum<0) return -1;

        return index;
    }
};
```



#### 최종

총합을 현재 총합, 배열의 총합을 나누어서 구한다. 현재 총합 같은 경우에는 인덱스로부터 시작해서 총합을 이야기하고 배열의 총합은 말그대로 배열의 모든 요소들을 더한 수이다. 이 때, 현재 총합이 음수이면 다른 수로부터 시작을 한다. 그 이유는 그 이전에 다른 숫자로 시작해도 음수의 값이 나오니 그 다음부터 시작하여 현재의 총합을 구하고 양수가 나오고 배열의 총합도 양수라는 것은 현재의 총합이 뒤에 있는 음수의 값들을 커버를 할 수 있다는 의미이니 이와 같이 구하였다.

```
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n=gas.size();
        int sum=0;
        int answer=-1;
        int total=0;
        for(int i=0;i<n;i++)
        {
            int num=gas[i]-cost[i];
            total+=num;

            if(answer==-1 && num>=0)
            {
                answer=i;
                sum+=num;
            }
            else if(answer!=-1)
            {
                sum+=num;

                if(sum<0)
                {
                    answer=-1;
                    sum=0;
                }
            }
        }

        if(total<0) return -1;

        return answer;
    }
};
```
