## 코테

### LeetCode 819. Most Common Word

#### 문제 요약

문자열이 주어졌을 때 가장 많이 나온 단어를 출력한다. 다만, banned에 있는 단어는 제외한다.

링크 : https://leetcode.com/problems/most-common-word/description/



#### 첫 번째 시도

처음에 문제를 풀 때 banned에 있는 단어들은 vector에 있기 때문에 탐색하기에는 시간이 걸릴거같아서 unordered_set으로 옮겼다. 그래도 unordered_set은 무조건 탐색이 O(1)이 아니기 때문에 1ms가 걸린 것으로 추정한다.

```
class Solution {
public:
    string mostCommonWord(string paragraph, vector<string>& banned) {
        unordered_map<string,int> m;
        unordered_set<string> us;
        string str="";

        for(string ban : banned)
        {
            us.insert(ban);
        }

        for(char c:paragraph)
        {
            if((c>='a' && c<='z') || (c>='A'&&c<='Z'))
            {
                str+=tolower(c);
            }
            else 
            {
                if(str=="") continue;

                m[str]++;
                str="";
            }
        }
        if(str!="")
        {
            m[str]++;
        }

        string answer="";
        int count=0;
        for(auto element:m)
        {
            string word=element.first;
            int word_count=element.second;
            if(us.find(word)==us.end() && ((word_count>count) || (word_count==count && answer>word)))
            {
                answer=word;
                count=word_count;
            }
        }
        return answer;
    }
};
```


#### 최종

그래서 banned에 있는 문자열들은 단어들을 다 탐색하고 난 뒤에 이들의 단어들을 0으로 초기화한다.

```
class Solution {
public:
    string mostCommonWord(string paragraph, vector<string>& banned) {
        unordered_map<string,int> m;
        unordered_set<string> us;
        string str="";

        for(char c:paragraph)
        {
            if((c>='a' && c<='z') || (c>='A'&&c<='Z'))
            {
                str+=tolower(c);
            }
            else 
            {
                if(str=="") continue;

                m[str]++;
                str="";
            }
        }
        if(str!="")
        {
            m[str]++;
        }

        for(string ban : banned)
        {
            m[ban]=0;
        }

        string answer="";
        int count=0;
        for(auto element:m)
        {
            string word=element.first;
            int word_count=element.second;
            if(((word_count>count) || (word_count==count && answer>word)))
            {
                answer=word;
                count=word_count;
            }
        }
        return answer;
    }
};
```



#### 나의 생각

입력 범위가 작고 집합 문제로 생각하여 바로 비트마스킹을 생각하였지만 그 시간까지 고려하지 못하였다. 빈 곳을 어떻게 넣을 수 있을까를 너무 비트마스킹으로만 제한하여서 생각해서 더 생각하지 못하였다. 좀 더 러프한 생각으로 문제를 풀어야겠다.
