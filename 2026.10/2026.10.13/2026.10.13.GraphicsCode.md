## CS (Graphics)

### wWinMain
- main()에 해당하는 역할
- LoadStringW : 리소스에 저장된 문자열을 가져온다
- MyRegisterClass : 창 클래스를 등록한다.
- InitInstance : 애플리케이션 초기화를 수행한다: 창을 생성하고 표시하는 함수
- GetMessage : 메시지 큐에서 메시지를 가져옴. 없으면 대기
- TranslateAccelerator : 등록된 메뉴 단축키 등을 처리
- Translatemessage : 키 메시지를 바탕으로 문자 메시지가 생성되도록 처리
- DispatchMessage : 해당 창의 메시지 처리 함수(WndProc)로 전달

### MyRegisterClass
- 창 클래스를 등록한다. 어떤 창을 만들지 등록
- wcex.lpfnWndProc    = WndProc; : 이 종류의 창에서 발생하는 메시지를 어떤 함수가 처리할지 지정
- wcex.lpszClassName  = szWindowClass; :  등록할 창 클래스의 이름
- return RegisterClassExW(&wcex); : 창의 설정을 채워 놓고 마지막에 등록함

### InitInstance
- 인스턴스 핸들을 저장하고 주 창을 만든다
- CreateWindowW : Window API로 창을 만든다.
- szWindowClass : 앞에서 등록한 창 클래스 사용
- L"Graphics Study" 제목 표시줄의 문자열
- WS_OVERLAPPEDWINDOW : 제목 표시줄, 크기 조절 테두리 등을 갖춘 일반적인 창 스타일
- CW_USEDEFAULT : 창의 위치와 크기 지정에 사용

### WndProc
- 주 창의 메시지를 처리합니다.
- WM_COMMAND  - 애플리케이션 메뉴를 처리합니다.
- WM_PAINT    - 주 창을 그립니다.
- WM_DESTROY  - 종료 메시지를 게시하고 반환합니다.
- hWnd : 어느 창의 메시지인지
- message : 어떤 종류의 메시지인지
- wParam, lParam : 해당 메시지에 딸린 추가 정보

#### 나의 생각
- 그래픽스 수업이나 DirextX 강의를 들으면서 함수를 쓴 것은 봤으나 이렇게까지 자세히 보지는 않았다. 한 번 스스로 모델링이나 엔진 등을 만들면서 배운 것을 응용해보아야겠다.
