## 컴퓨터 구조

### 컴퓨터 구조를 배워야 하는 이유

#### 성능, 비용, 용량

- 상황, 자본 등에 따라서 컴퓨터의 성능, 비용, 용량을 선택할 수 있다
  
  - 예를 들어, 싼 컴퓨터를 사도 되지만 비싼 컴퓨터를 사게 되는 등

#### 문제 해결

- 로직, 문법을 잘 짜도 각 컴퓨터에 따라서 실행이 안되는 경우도 있음
  
  - 따라서, 코드만 보는 것이 아닌 컴퓨터까지 깊이 분석하여 문제를 해결할 수 있음

#### 컴퓨터가 이해하는 정보

데이터

- 숫자, 문자, 이미지, 동영상과 같은 정적인 정보

- 컴퓨터와 주고받는/내부에 저장된 정보를 데이터라 통칭하기도 한다

- 0과 1로 숫자를 표현하는 방법

- 0과 1로 문자를 표현하는 방법

명령어

- 컴퓨터를 실질적으로 움직이는 정보

- 데이터는 명령어를 위한 일종의 재료
  
  

#### 컴퓨터의 네 가지 핵심 부품

![7a737b6e-9a61-4b55-aafd-5ff76686fc40](file:///C:/Users/admin/Pictures/Typedown/7a737b6e-9a61-4b55-aafd-5ff76686fc40.png)

메모리

- 프로세스의 명령어와 데이터를 저장하는 부품

- 프로그램이 실행되기 위해서는 메모리에 저장되어 있어야 한다.

- 메모리는 실행되는 프로그램의 명령어와 데이터를 저장한다

- 메모리에 저장된 값의 위치는 주소로 알 수 있다.

- ex)등 RAM, ROM 등

![3e7cf6c5-833d-446d-8460-352c1e12463b](file:///C:/Users/admin/Pictures/Typedown/3e7cf6c5-833d-446d-8460-352c1e12463b.png)

CPU

- 메모리에 저장된 명령어를 읽어 들이고, 해석하고, 실행하는 부품

- CPU는 메모리에 저장된 값을 읽어 들이고, 해석하고, 실행하는 장치다

- CPU 내부에는 ALU, 레지스터, 제어장치가 있다.
  
  - ALU : 산술 연산, 논리 연산을 한다
  
  - 레지스터 : CPU 내부의 작은 저장장치
  
  - 제어장치 : 제어 신호를 내보내고, 명령어를 해석하는 장치
    
    - 제어 신호 : 컴퓨터 부품들을 관리하고 작동시키기 위한 전기 신호
    
    - CPU가 메모리에 저장된 값을 읽고 싶을 땐 메모리를 향해 메모리 읽기라는 제어 신호를 보낸다
    
    - CPU가 메모리에 어떤 값을 저장하고 싶을 땐 메모리를 향해 메모리 쓰기라는 제어 신호를 보낸다

- 메모리 읽기 예시)
  
  - 제어장치에서 메모리 읽기 제어 신호를 보냄
  
  - 메모리 1번지의 명령어를 읽어 레지스터에 저장한다
  
  - 제어장치는 명령어를 읽고 3번지와 4번지의 메모리를 읽는 제어 신호를 보낸다
  
  - 메모리 3,4번지의 데이터를 레지스터에 저장한 뒤, ALU에서 이 레지스터에 있는 데이터를 더하는 명령어를 실행한다.
  
  - 더한 데이터는 다른 레지스터에 저장한다

  - 메모리 2번지의 명령어를 읽어 레지스터에 저장한다

보조기억장치

- 메인 메모리는 비싸고 전원이 꺼지면 저장된 내용을 잃는다. (비휘발성 메모리는 유지된다)

- 전원이 꺼져도 보관될 프로그램을 저장하는 부품이다

- 메모리를 실행할 정보를 저장하고 보조기억장치는 보관할 정보를 저장한다

- ex) 디스크, SSD 등등

입출력장치

- 컴퓨터 외부에 연결되어 컴퓨터 내부와 정보를 교환할 수 있는 부품

- ex) 키보드, 모니터 등



메인보드

- 메인보드에 연결된 부품은 버스를 통해 정보를 주고 받음

- 버스는 컴퓨터의 부품끼리 정보를 주고받는 일종의 통로

- 다양한 종류의 버스가 있음

- 컴퓨터의 핵심 부품을 연결하는 버스는 시스템 버스

시스템 버스

- 시스템 버스의 내부 구성
  
  - 주소 버스 : 주소를 주고받는 통로
  
  - 데이터 버스 : 명령어와 데이터를 주고받는 통로
  
  - 제어 버스 : 제어 신호를 주고받는 통로
