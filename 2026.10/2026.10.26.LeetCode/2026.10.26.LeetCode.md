## 코테

### LeetCode 947. Most Stones Removed with Same Row or Column

#### 문제 요약

같은 행 또는 열에서 공유하는 돌들 최대한 지워버리는 문제

링크 : https://leetcode.com/problems/most-stones-removed-with-same-row-or-column/description/



#### 첫 번째 시도

같은 행 또는 열에서 공유하는 것을 생각을 하여 UnionFind 알고리즘을 생각하였다. 이 알고리즘을 사용해서 한 그룹으로 만들고 한 개의 돌을 제외한 나머지를 제거하는 방식으로 생각하였다. 이 때 그룹을 만들 때 같은 row끼리 같은 col끼리 묶어주고 그 안에 있는 요소들끼리 UnionFind 알고리즘을 적용한 뒤 그룹을 셀 때 다시 한 번 더 Union할게 있는지 확인하고 그룹에 있는 요소들을 세는 방식으로 진행하였다. 

```
class Solution {
    vector<int> parent, size;
    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) swap(a, b);
        parent[b] = a;
        size[a] += size[b];
    }
public:
    int removeStones(vector<vector<int>>& stones) {
        int n = stones.size();
        parent.resize(n); iota(parent.begin(), parent.end(), 0);
        size.assign(n, 1);
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (stones[i][0] == stones[j][0] || stones[i][1] == stones[j][1])
                    unite(i, j);
        int components = 0;
        for (int i = 0; i < n; i++) if (find(i) == i) components++;
        return n - components;
    }
};
```



#### 최종

시간을 더 줄일 수 있을거라고 생각을 하여 수정을 하였다. 첫 번째로는 Union하기 위해 이중문을 사용하였는데 그렇게 하지 않고 그 열을 처음 들어오는 숫자를 대표 숫자로 정하여 이를 기준으로 Union하는 방식으로 하였다. 두 번째로는 그룹의 한 요소를 빼고 나머지를 뺴는 방식이기 떄문에 순회를 하지 않고 전체에 그룹을 빼는 방식으로 하였다

#### 나의 생각

처음에 문제를 풀 때는 UnionFind 알고리즘을 사용해야 겠다고는 생각했다. 그리고 본인이 푸는 템플릿으로 풀었는데 풀었지만 시간이 걸렸다. 인덱스가 낮은 것으로 몰아주는 과정을 거쳤는데 그렇게 한다면 첫 번째 시도와 같이 순회를 많이 해야한다. 즉,대표적인 숫자 하나로 몰아준다면 그러한 과정은 없는 것이다. 이제 템플릿이 아닌 더 나은 과정으로 문제를 풀어야겠다고 생각을 하였다.
