## 코테

### LeetCode 73. Set Matrix Zeros

#### 문제 요약

좌표에서 0을 발견하면 그에 대한 행과 열을 0으로 만들어야 한다. 대신 in place로 해야한다

링크 : https://leetcode.com/problems/set-matrix-zeroes/description/



#### 최종

처음에는 0을 발견하고 그에 대한 행과 열에 대한 인덱스를 저장하고 싶었지만 in-place로 해야한다는 점에서 문제의 의도와 같지 않다. 고민해도 해결 방법이 생각나지 않아 힌트를 보았다.

힌트를 본 결과, 먼저 0번째 행에서 0이 존재하는지 0번째 열에서 0이 존재하는지 파악한다. 그 다음, 1번째 행 이후, 1번째 열 이후 0이 존재하면 0번째에서 0으로 만들어준다. 

그 다음, 0번째 행 또는 0번째 열에서 0을 발견하면 그 이후에 대해서 다 0으로 만든다. 마지막으로 맨 처음에 봤던 0번째 행 또는 0번째 열에서 0이 있는지 파악했던 것을 이용해서 그 행 또는 열을 0으로 만든다. 

```
 class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int n=matrix.size();
        int m=matrix[0].size();

        bool zeroCol=false;
        bool zeroRow=false;

        for(int i=0;i<n;i++)
        {
            if(matrix[i][0]==0)
            {
                zeroCol=true;
            }
        }

        for(int i=0;i<m;i++)
        {
            if(matrix[0][i]==0)
            {
                zeroRow=true;
            }
        }

        for(int i=1;i<n;i++)
        {
            for(int j=1;j<m;j++)
            {
                if(matrix[i][j]==0)
                {
                    matrix[i][0]=0;
                    matrix[0][j]=0;
                }
            }
        }

        for(int i=1;i<n;i++)
        {
            if(matrix[i][0]==0)
            {
                for(int j=0;j<m;j++)
                {
                    matrix[i][j]=0;
                }
            }
        }

        for(int i=1;i<m;i++)
        {
            if(matrix[0][i]==0)
            {
                for(int j=0;j<n;j++)
                {
                    matrix[j][i]=0;
                }
            }
        }

        if(zeroCol)
        {
            for(int i=0;i<n;i++)
            {
                matrix[i][0]=0;
            }
        }
        if(zeroRow)
        {
            for(int i=0;i<m;i++)
            {
                matrix[0][i]=0;
            }
        }
    }
};
```



#### 나의 생각

처음에 이 문제를 풀 때는 0을 발견할 때 그에 대한 행과 열을 저장하려고 하였지만 그러면 문제에 대한 의도대로 못 풀며 O(n+m)의 공간복잡도를 가진다. 계속 고민을 하여도 생각이 나지 않아 힌트를 보았다. 이 문제는 알고리즘보다는 생각의 전환을 가져야하는 문제이다
