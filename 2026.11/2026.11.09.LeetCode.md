## 코테

### LeetCode 547. Number of Provinces

#### 문제 요약

connected가 표시된 배열을 보고 총 그룹의 개수를 출력하는 문제

링크 : https://leetcode.com/problems/number-of-provinces/description/



#### 최종

그룹으로 묶어야 하는 문제로 먼저 Union-Find 알고리즘을 생각하였다. 그리고 isConnected 배열에서 순회를 하면서 Union의 과정을 거쳐 그룹을 만들어 낸다. 최종 출력 하기 전에 같은 배열이어도 다른 쪽에서 배열의 과정을 거칠 수 있으니 Union의 과정을 거쳐서 출력 하는 과정을 거쳤다.

```
class Solution {
public:
    vector<int> root;
    
    int Find(int x)
    {
        if(x==root[x]) return x;

        return root[x]=Find(root[x]);
    }

    void Union(int x,int y)
    {
        x=Find(x);
        y=Find(y);

        if(x!=y)
        {
            root[y]=root[x];
        }
    }

    int findCircleNum(vector<vector<int>>& isConnected) {
        int n=isConnected.size();
        for(int i=0;i<n;i++)
        {
            root.push_back(i);
        }

        for(int i=0;i<n;i++)
        {
            int num=-1;
            for(int j=0;j<n;j++)
            {
                if(num==-1&&isConnected[i][j]==1)
                {
                    num=j;
                    if(root[i]!=root[j])
                    {
                        Union(i,j);
                    }
                }
                else if(isConnected[i][j]==1)
                {
                    if(root[num]!=root[j])
                    {
                        Union(num,j);
                    }
                }
            }
        }

        unordered_set<int> us;
        for(int i=0;i<n;i++)
        {
            Union(root[i],i);
            us.insert(root[i]);
        }

        return us.size();
    }
};
```



#### 나의 생각

Union-Find 알고리즘 어느 정도 익숙해지고 더 심화를 문제를 풀거나 다른 문제의 형식으로 바꿔야겠다
