## 코테

### LeetCode 981. Time Based Key-Value Store

#### 문제 요약

시간에 따라서 key의 value값을 출력하는 문제

링크 : https://leetcode.com/problems/time-based-key-value-store/description/



#### 첫번째 시도

key의 value값을 출력하는 문제이기 때문에 map을 생각하였다. 그리고 시간에 따라서 갱신되는 값이 달라지기 때문에 map을 key에 따른 vector<int,string> value 값을 또 다른 map은 key의 시간이 몇 번째 인덱스에 위치해 있는지 파악하기 위한 map을 만들어서 value 값을 도출하였다. 

```
class TimeMap {
public:
    map<string, vector<pair<int,string>>> m;
    unordered_map<string,int> cur_idx;
    TimeMap() {
        m.clear();
    }
    
    void set(string key, string value, int timestamp) {
        if(m.find(key)==m.end())
        {
            vector<pair<int,string>> v;
            v.push_back({timestamp,value});
            m[key]=v;
            cur_idx[key]=0;
        }
        else
        {
            m[key].push_back({timestamp,value});
        }
    }
    
    string get(string key, int timestamp) {
        string answer;

        for(int i=cur_idx[key];i<m[key].size();i++)
        {
            pair<int,string>& element = m[key][i];

            if(element.first<=timestamp)
            {
                answer=element.second;
                cur_idx[key]=i;
            }
            else if(answer!="")
            {
                break;
            }
        }

        return answer;
    }
};

/**
 * Your TimeMap object will be instantiated and called as such:
 * TimeMap* obj = new TimeMap();
 * obj->set(key,value,timestamp);
 * string param_2 = obj->get(key,timestamp);
 */
```



#### 다른 문제 풀이법

위의 풀이 방법과는 유사하지만 다른 점이 있다면 key 찾는 방법을 upper_bound를 사용하는 것이다. 위의 방법을 사용하게 된다면 O(n)의 시간이 걸리지만 upper_bound는 O(logN)의 시간이 걸린다. upper_bound를 사용하는 이유는 특정 스탬프 보다 큰 첫번째 인덱스를 찾게 되고 그 이전은 같거나 특정 스탬프보다 작은 값이 나오기 때문에 upper_bound를 사용한다. 

```
class TimeMap {
public:
    // key별로 {timestamp, value} 쌍을 저장하는 구조
    unordered_map<string, vector<pair<int, string>>> m;

    TimeMap() {}
    
    void set(string key, string value, int timestamp) {
        // 타임스탬프가 항상 증가하는 순서로 들어오므로 push_back만 해도 항상 정렬 상태 유지!
        m[key].push_back({timestamp, value});
    }
    
    string get(string key, int timestamp) {
        // 만약 해당 key가 아예 없다면 빈 문자열 리턴
        if (m.find(key) == m.end()) return "";

        const auto& v = m[key];

        // upper_bound를 쓰기 위해 비교용 dummy pair 생성 
        // (timestamp가 일치하거나 큰 첫 번째 위치를 찾기 위함)
        auto it = upper_bound(v.begin(), v.end(), make_pair(timestamp, string("~")), 
            [](const pair<int, string>& a, const pair<int, string>& b) {
                return a.first < b.first;
            });

        // 만약 첫 번째 원소보다도 작다면 유효한 값이 없는 것
        if (it == v.begin()) return "";

        // upper_bound가 가리키는 곳의 바로 왼쪽 칸이 'timestamp 이하'인 가장 최신 값입니다.
        return (it - 1)->second;
    }
};
```
