## 코테

### LeetCode 404. Sum of Left Leaves

#### 문제 요약

트리의 왼쪽 리프 노드의 합을 구하기

링크 : https://leetcode.com/problems/sum-of-left-leaves/description/



#### 최종

왼쪽인지 아닌지 판단을 하고 리프 노드인지도 판단을 하여 그것들의 합을 재귀로 구한다

```
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int Sum(bool left, TreeNode* root)
    {
        int sum=0;
        if(root==nullptr)
        {
            return sum;
        }

        if(left && (root->left==nullptr && root->right==nullptr))
        {
            return root->val;
        }

        sum+=Sum(true,root->left);
        sum+=Sum(false,root->right);

        return sum;
    }
    int sumOfLeftLeaves(TreeNode* root) {
        return Sum(false,root);
    }
};
```
