## 코테

### LeetCode 1143. Longest Common Subsequence

#### 문제 요약

text1과 text2가 주어질 때 순서는 유지하면서 같은 문자가 몇 개인지 출력하는 문제

링크 : https://leetcode.com/problems/longest-common-subsequence/description/



#### 첫 번째 시도

2차원의 배열을 만들어서 문자가 같다면 그 이전의 행과 그 이전의 열에서 +1을 한다. 만약 다르면 그 이전의 행 또는 그 이전의 열 중 가장 큰 값을 가져온다. 즉, dp 형식으로 문제 푼다. dp로 문제 푸는 이유는 작은 문자열로 나누고 그 결과를 저장해 재사용함으로써 전체 문자열로 해결할 수 있기 때문이다. 

```
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int n=text1.length();
        int m=text2.length();

        vector<vector<int>> dp(n+1, vector<int>(m+1,0));

        for(int i=0;i<n;i++)
        {
            for(int j=0;j<m;j++)
            {
                if(text1[i]!=text2[j])
                {
                    dp[i+1][j+1]=max(dp[i+1][j],dp[i][j+1]);
                }
                else
                {
                    dp[i+1][j+1]=dp[i][j]+1;
                }
            }
        }

        return dp[n][m];
    }
};
```



#### 최종

이 문제의 경우에는 이전 행과 이전 열의 값 그리고 이전 행이면서 이전 열의 값을 알면 되기 때문에 1차 배열로 구할 수 있다. 또한, 짧은 문자열을 열로 둠으로써 캐시 라인을 가져와 캐시 미스를 덜 유발할 수 있기 때문에 시간도 덜 걸리게 된다. 

```
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        // 항상 text1이 더 짧거나 같도록 유지하여 메모리 사용량 최소화
        if (text1.length() < text2.length()) 
        {
            swap(text1, text2);
        }

        int n = text1.length();
        int m = text2.length();

        // 긴 문자열이 행, 짧은 문자열이 열 역할을 하도록 크기를 m(짧은 쪽)으로 설정
        vector<int> dp(m + 1, 0);

        for (int i = 0; i < n; i++) 
        {
            int prev = 0; // 대각선 위 값(dp[i-1][j-1])을 임시 저장할 변수
            for (int j = 0; j < m; j++) 
            {
                int temp = dp[j + 1]; // 다음 루프를 위해 현재 dp[j+1] 백업
                if (text1[i] == text2[j]) 
                {
                    dp[j + 1] = prev + 1;
                } 
                else 
                {
                    dp[j + 1] = max(dp[j + 1], dp[j]);
                }
                prev = temp;
            }
        }

        return dp[m];
    }
};
```



#### 나의 생각

문제 자체는 어렵진 않았지만 이런 식으로 메모리의 연속성과 캐시 라인을 고민하면서 문제를 풀어야겠다고 생각이 든다.
