## 코테

### LeetCode 735. Asteroid Collision

#### 문제 요약

상대적인 간격의 위치의 행성들이 있다. 그리고 그 크기들과 움직이는 방향이 정해진 배열이 주어졌다. 이 때 행성과 부딪힐 때 크기가 큰 행성이 살아남고 같은 크기면 두 행성은 사라진다.

링크 : https://leetcode.com/problems/asteroid-collision/description/



#### 최종

배열을 만들어서 스택처럼 푸는 방식으로 채택하였다. 그래서 마지막 부분이 양수이고 현재 행성이 음수일 때 크기 비교를 하고 같으면 빼버리고 현재행성이 작다면 그대로 넘어간다. 만약 현재 행성이 크면 배열 부분이 비어질 때까지 계속 빼고 크기 비교 하는 방식으로 진행한다

```
class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        vector<int> answer;

        for(int asteroid : asteroids)
        {
            bool put=true;

            while(!answer.empty())
            {
                int back_ast=answer.back();

                if(back_ast>0 && asteroid<0)
                {
                    if(abs(back_ast)<abs(asteroid))
                    {
                        answer.pop_back();
                    }
                    else if(abs(back_ast)==abs(asteroid))
                    {
                        answer.pop_back();
                        put=false;
                        break;
                    }
                    else
                    {
                        put=false;
                        break;
                    }
                }
                else 
                {
                    break;
                }
            }

            if(put)
            {
                answer.push_back(asteroid);
            }
        }

        return answer;
    }
};
```
