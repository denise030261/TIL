## 코테

### LeetCode 763. Partition Labels

#### 문제요약

주어진 문자열에서 그룹을 나누되 같은 문자들끼리 한 그룹에 있어야 한다

링크 : https://leetcode.com/problems/partition-labels/description/



#### 첫 번째 풀이

이 문제를 봤을 때 문자의 첫 번째 나오는 인덱스와 마지막으로 나오는 인덱스를 추출하여 정렬을 한 뒤에 다음에 나오는 첫번째 인덱스가 현재의 두번째 인덱스보다 작으면 문자가 그 안에 포함되어 있으므로 두 번째 인덱스에서 큰 값을 갱신한다. 반대로 첫 번째 인덱스가 큰 값보다 크면 문자열이 구분될 수 있으므로 답의 길이를 갱신한다.

```
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> answer;
        int n=s.length();
        unordered_map<char,pair<int,int>> um;
        
        for(int i=0;i<n;i++)
        {
            char c=s[i];
            if(um.find(c)!=um.end())
            {
                um[c].second=i;
            }
            else
            {
                um[c]={i,i};
            }
        }

        vector<pair<int,int>> v;
        for(auto& element : um)
        {
            v.push_back(element.second);
        }
        sort(v.begin(), v.end());

        int min_num=v[0].first;
        int max_num=v[0].second;
        for(int i=0;i<v.size();i++)
        {
            int cur_min=v[i].first;
            int cur_max=v[i].second;

            if(cur_min>max_num)
            {
                answer.push_back(max_num-min_num+1);
                min_num=cur_min;
                max_num=cur_max;
            }
            else
            {
                max_num=max(max_num,cur_max);
            }
        }
        answer.push_back(max_num-min_num+1);

        return answer;
    }
};
```



#### 다른 사람의 코드

첫 번째 방법으로 하게 된다면 2ms가 거린다. 대부분은 0ms가 걸렸는데 확인하니 문자 중에 마지막에 나오는 인덱스만 저장을 하였고 따로 정렬을 하지 않았다. 대신에 문자열을 다시 순회하면서 앞에 나온 문자 중에서 제일 나중에 나온 문자의 인덱스 값을 갱신하고 그 인덱스 값 번째 일 때 총 길이를 답을 추출하는 방식으로 풀었다.

```
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> arr(26,0);
        vector<int> answer;
        int n=s.length();

        for(int i=0;i<n;i++)
        {
            arr[s[i]-'a']=i;
        }

        int length=0;
        int last=0;
        for(int i=0;i<n;i++)
        {
            last=max(last,arr[s[i]-'a']);
            length++;
            if(i==last)
            {
                answer.push_back(length);
                length=0;
                last=0;
            }
        }

        return answer;
    }
};
```
