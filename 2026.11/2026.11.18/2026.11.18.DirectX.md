## CS(DirectX)

### TrasformData 변경

```
#include <DirectXMath.h>

namespace
{
    struct TransformData
    {
        DirectX::XMFLOAT4X4 localToClip;
    };

    static_assert(
        sizeof(TransformData) == 64,
        "TransformData must be 64 bytes"
    );
}
```

- 64인 이유는 XMFLOAT4X4는 실수 16개로 구성된 4x4 행렬 저장용 타입이기 때문이다

- localToClip인 이유는 집의 원본에 클립 좌표로 바꾸기 때문이다



### Render() 변경

```
for (const House& house : houses)
{
    // 크기 조절: 2D이므로 Z축 크기는 유지
    const DirectX::XMMATRIX scale =
        DirectX::XMMatrixScaling(
            house.scale,
            house.scale,
            1.0f
        );

    // Z축을 중심으로 회전
    const DirectX::XMMATRIX rotation =
        DirectX::XMMatrixRotationZ(house.rotation);

    // 기존 셰이더의 x /= aspectRatio와 같은 역할
    const DirectX::XMMATRIX aspectCorrection =
        DirectX::XMMatrixScaling(
            1.0f / m_aspectRatio,
            1.0f,
            1.0f
        );

    // 이동
    const DirectX::XMMATRIX translation =
        DirectX::XMMatrixTranslation(
            house.x,
            house.y,
            house.z
        );

    // 기존 계산 순서 유지
    const DirectX::XMMATRIX localToClip =
        scale * rotation * aspectCorrection * translation;

    TransformData data{};

    DirectX::XMStoreFloat4x4(
        &data.localToClip,
        localToClip
    );

    m_context->UpdateSubresource(
        m_constantBuffer.Get(),
        0,
        nullptr,
        &data,
        0,
        0
    );

    m_context->DrawIndexed(m_indexCount, 0, 0);
}
```

| 타입           | 이번 코드에서의 역할               |
| ------------ | ------------------------- |
| `XMMATRIX`   | 행렬을 만들고 곱하는 계산용           |
| `XMFLOAT4X4` | 계산 결과를 상수 버퍼에 전달하기 위한 저장용 |

- 행렬은 곱하는 순서가 중요하다. 왼쪽부터 크기 조절, 회전, 화면 비율 보정, 이동을 적용한다



### 셰이더 변경

```
cbuffer TransformBuffer : register(b0)
{
    row_major float4x4 localToClip;
};

struct VSInput
{
    float3 position : POSITION;
    float4 color    : COLOR;
};

struct VSOutput
{
    float4 position : SV_POSITION;
    float4 color    : COLOR;
};

VSOutput VSMain(VSInput input)
{
    VSOutput output;

    output.position = mul(
        float4(input.position, 1.0f),
        localToClip
    );

    output.color = input.color;

    return output;
}

float4 PSMain(VSOutput input) : SV_TARGET
{
    return input.color;
}
```

- 수동 회전 계산으로 하지 않기 때문에 수정한다
