## 코테

### LeetCode 438. Find All Anagrams in a String

#### 문제 요약

주어진 문자열 s와 p가 있다. 이 때 s의 부분 문자열에 p의 문자들이 다 있는지 그리고 그의 시작점을 출력하는 문제

링크 : https://leetcode.com/problems/find-all-anagrams-in-a-string/description/



#### 첫번째 시도

dp로 풀까 하였지만 그러기에는 하위 문제 풀린다고 해서 상위 문제로 풀 수 없다고 생각이 들었고 대신에 투 포인터를 이용해서 p에 있는 문자들을 카운팅하기로 하였다. end를 쭉 넘기되 p에 있는 문자가 다 있으면 그 때 확인하는 식으로 풀었다. 이 때 문자가 다 있는지 파악하는 방법은 unordered_map을 사용하면서 진행하였다. 근데 이렇게 풀어버리면 start의 지점을 검사하는 식에 처리를 해야하고 그렇게 진행함으로써 로직이 복잡해진다. 

```
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> answer;
        unordered_map<char,int> um;
        int n=s.length();

        for(char c : p)
        {
            um[c]++;
        }

        int start=0;
        int end=0;
        int count=p.length();
        while(start<n-p.length()+1 && end<n)
        {
            if(um.find(s[end])!=um.end() && um[s[end]]>0)
            {
                count--;
                um[s[end]]--;
            }

            if(count==0)
            {
                while(end-start+1>p.length())
                {
                    if(um.find(s[start])!=um.end() && um[s[start]]<0)
                    {
                        um[s[start]]++;
                        count++;
                    }
                    start++;
                }

                if(count==0)
                {
                    answer.push_back(start);
                }

                if(um.find(s[start])!=um.end())
                {
                    um[s[start]]++;
                    count++;
                }
                start++;
                end++;
                continue;
            }
            
            if(end+1<n)
            {
                end++;
            }
            else
            {
                start++;
            }
        }
        return answer;
    }
};
```



#### 최종

end를 늘리되 p의 문자열 크기가 되면 p의 문자들이 다 있는지 확인하고 start를 늘리는 방식으로 진행한다. 그래서 이전 문제 풀이처럼 end만 늘리고 count가 0일 대 start를 늘리는 방식이 아닌 end와 start의 사이가 p의 문자열 크기만큼 확인하면서 옆으로 옮겨나가는 방식이다

```
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> answer;
        if(s.length()<p.length()) return answer;

        unordered_map<char,int> um;
        for(char c : p)
        {
            um[c]++;
        }

        int count=p.length();
        int start=0, end=0;
        int n=s.length();

        while(end<n)
        {
            if(um.count(s[end]) && um[s[end]]>0)
            {
                count--;
            }
            if(um.count(s[end]))
            {
                um[s[end]]--;
            }
            end++;

            if(end-start==p.length())
            {
                if(count==0)
                {
                    answer.push_back(start);
                }

                if(um.count(s[start]))
                {
                    if(um[s[start]]>=0)
                    {
                        count++;
                    }
                    um[s[start]]++;
                }
                start++;
            }
        }

        return answer;
    }
};
```
