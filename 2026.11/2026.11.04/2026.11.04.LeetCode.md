## 코테

### LeetCode 853. Car Fleet

#### 문제 요약

각자 차들이 target을 향해 움직이게 되는데 그 때, 뒤에 차가 빨라도 앞에 차가 느리면 그 차에 속도에 맞게 움직인다. 그 때 차의 그룹은 몇 개 생기는가

링크 : https://leetcode.com/problems/car-fleet/description/



#### 최종

이 문제는 차가 아무리 빨라도 앞에 차가 느리면 빠르게 못 가기 때문에 이를 고려를 해야한다. 그래서 먼저 각 차들이 target에 도착하는데 얼마나 걸리는지 파악하고 정렬을 한다. 그 때, position이 target과 제일 가까운 순 부터 정렬을 한다. 그래서 만약 뒤 차가 앞 차보다 빠르게 도착하면 앞 차와 한 그룹이 되는 방식으로 구하였다

```
class Solution {
public:
    static bool compare(pair<int,float>& a,pair<int,float>& b)
    {
        if(a.first==b.first)
        {
            return a.second>b.second;
        }

        return a.first>b.first;
    }
    int carFleet(int target, vector<int>& position, vector<int>& speed) {
        int answer=0;
        int n=position.size();

        vector<pair<int,float>> v;
        for(int i=0;i<n;i++)
        {
            float second=((float)(target-position[i]))/(float)speed[i];
            v.push_back({position[i],second});
        }
        sort(v.begin(), v.end(), compare);

        answer++;
        float time=v[0].second;

        for(int i=1;i<n;i++)
        {
            if(time<v[i].second)
            {
                time=v[i].second;
                answer++;
            }
        }

        return answer;
    }
};
```



#### 나의 생각

그리디 알고리즘으로 앞에 있는 차의 시간에 따라서 답이 갈라진다. 그리디는 확실히 생각이 나면 바로 문제 풀기 쉬워지지만 그렇지 않은 경우에는 찾기가 많이 힘든것 같다
