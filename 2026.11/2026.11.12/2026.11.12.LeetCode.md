## 코테

### LeetCode 287. Find the Duplicate Number

#### 문제 요약

주어진 배열을 이용해서 중복된 숫자 찾기. 배열은 수정하면 안되고 공간복잡도는 O(1)이며 중복숫자는 오직 하나이다. 또한, 중복 숫자는 2개 이상이 존재한다.

링크 : https://leetcode.com/problems/find-the-duplicate-number/description/



#### 첫 번째 시도

처음에는 평균을 이용하여서 중복 숫자를 찾으려고 했다. 근데 그렇게 하면 시간복잡도가 O(N^2)이 되며 중복숫자가 2개라는 법은 없기 때문에 풀 수가 없다. 



#### 두 번째 시도

힌트를 보았다. nums에 있는 숫자에 인덱스로 이동하게 되면 순환이 발생하게 된다. 그 때 폴로이드의 거북이와 토끼 알고리즘을 사용하면 된다. 이 알고리즘의 경우에는 지금과 같이 노드 간의 서로 연결되어있고 순환이 발생했을 때 순환 발생 시작점을 찾을 수 있도록 하는 알고리즘이다. 

```
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int n=nums.size();
        int rabbit=0;
        int turtle=0;

        // 토끼는 2번, 거북이는 1번
        do {
            turtle = nums[turtle];
            rabbit = nums[nums[rabbit]];
        } while (turtle != rabbit);

        // 출발점 맞추기
        turtle=0;
        while(rabbit!=turtle)
        {
            rabbit=nums[rabbit];
            turtle=nums[turtle];
        }

        return rabbit;
    }
};
```



#### 다른 사람의 코드

본인은 4ms가 걸려서 다른 사람은 어떻게 빠르게 하나 보았는데 문제에서는 nums의 순서를 바꾸면 안되는데 바꿔서 시간 단축을 한 사람이 있다. 이 방법은 맨 처음에 있는 숫자와 그 숫자 순서에 있는 숫자와 비교하여 다르다면 원래에 있어야할 인덱스에 숫자를 넣는 것이다. 이를 반복하는데 만약에 같다면 중복숫자라는 의미로 그 숫자를 출력하면 된다. 

```
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        while (nums[0] != nums[nums[0]])
            swap(nums[0], nums[nums[0]]);
        return nums[0];
    }
};
```



#### 나의 생각

어제에 이어서 제약이 없으면 쉽게 풀 수 있는 문제이지만 아니라면 급격히 난이도가 올라가는 문제이다. 이번 문제의 경우에는 이 알고리즘을 몰랐다면 아예 몰랐을 문제였을 것이다. 이러한 문제들도 풀다보면 나중에 구현에서 좋은 밑거름이 될 것 같다.
