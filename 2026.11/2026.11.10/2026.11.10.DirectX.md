### 위치 이동

#### 1. 이동량을 담을 구조체와 버퍼 추가

```
struct TransformData
{
    float offsetX;
    float offsetY;
    float offsetZ;
    float padding; // 크기를 16바이트로 맞추기 위한 여분
};

static_assert(sizeof(TransformData) == 16);

ComPtr<ID3D11Buffer> g_constantBuffer;

HRESULT InitConstantBuffer();
```

- 상수 버퍼는 이동량, 변환 행렬, 조명 정보처럼 셰이더가 읽을 데이터를 전달하는 버퍼

- DirectX11 상수 버퍼의 크기는 16바이트의 배수여야 하므로 float 4개로 구성

#### 4. 정점 셰이더에 이동량 사용

```
const char g_shaderSource[] = R"(
cbuffer TransformBuffer : register(b0)
{
    float4 moveOffset;
};
...

VSOutput VSMain(VSInput input)
{
    VSOutput output;

    float3 movedPosition = input.position + moveOffset.xyz; // 실제 이동시키는 코드

    output.position = float4(movedPosition, 1.0f);
    output.color = input.color;

    return output;
}
...
)";드
```

* `cbuffer`: 상수 버퍼 선언.
* `register(b0)`: 상수 버퍼 슬롯 **0번**에서 읽겠다는 뜻.
* `moveOffset`: C++에서 전달한 실수 4개를 받는 변수.

| C++       | HLSL                          |
| --------- | ----------------------------- |
| `offsetX` | `moveOffset.x`                |
| `offsetY` | `moveOffset.y`                |
| `offsetZ` | `moveOffset.z`                |
| `padding` | `moveOffset.w` — 이번에는 사용하지 않음 |



#### 5. Render()에서 데이터를 보내고 연결하기

```
// CPU에서 이동량 준비
TransformData transform{};
transform.offsetX = 0.2f;
transform.offsetY = 0.0f;
transform.offsetZ = 0.0f;

// CPU 데이터를 상수 버퍼로 복사
g_context->UpdateSubresource(
    g_constantBuffer.Get(),
    0,
    nullptr,
    &transform,
    0,
    0
);

// 정점 셰이더의 상수 버퍼 슬롯 0번에 연결
ID3D11Buffer* constantBuffer = g_constantBuffer.Get();

g_context->VSSetConstantBuffers(
    0,                  // 시작 슬롯: HLSL의 b0과 대응
    1,                  // 연결할 버퍼 개수
    &constantBuffer
);

// 기존 그리기 명령
g_context->DrawIndexed(g_indexCount, 0, 0);
```

- VSSetConstantBuffers() : 상수 버퍼를 정점 셰이더에서 사용할 슬롯에 연결하는 함수

| 함수                       | 역할             |
| ------------------------ | -------------- |
| `UpdateSubresource()`    | 버퍼에 이동량을 복사    |
| `VSSetConstantBuffers()` | 셰이더가 읽을 버퍼를 연결 |

#### 자리 이동 Update() 교체

```
void Update(float deltaTime)
{
    float directionX = 0.0f;
    float directionY = 0.0f;

    // 키 입력으로 이동 방향 결정
    if (g_keyDown[VK_LEFT])
    {
        directionX -= 1.0f;
    }

    if (g_keyDown[VK_RIGHT])
    {
        directionX += 1.0f;
    }

    if (g_keyDown[VK_UP])
    {
        directionY += 1.0f;
    }

    if (g_keyDown[VK_DOWN])
    {
        directionY -= 1.0f;
    }

    // 방향 벡터의 길이
    const float length = std::sqrt(
        directionX * directionX +
        directionY * directionY
    );

    // 입력이 없거나 반대 방향 입력이 상쇄되면 이동하지 않음
    if (length == 0.0f)
    {
        return;
    }

    // 대각선 이동도 같은 좌표계 속도가 되도록 정규화
    directionX /= length;
    directionY /= length;

    const float moveSpeed = 0.3f; // 초당 이동량

    g_transform.offsetX += directionX * moveSpeed * deltaTime;
    g_transform.offsetY += directionY * moveSpeed * deltaTime;
}
```
